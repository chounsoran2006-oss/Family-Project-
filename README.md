# My Family Website

A modern family website for the CHUON family in Oddar Meanchey Province, Cambodia.

## Project files

- `index.html` – homepage
- `about.html` – story and family overview
- `family.html` – family members
- `gallery.html` – image gallery with lightbox and filters
- `memories.html` – timeline and family memories
- `contact.html` – contact form and details
- `css/style.css` – shared styling and responsive layout
- `js/script.js` – menu, lightbox, reveal animations, counters, and validation

## Run locally

Open the folder in a browser or use a simple local server:

```bash
cd "c:\Users\SORAN.CHUON\Desktop\Family-Project-"
python -m http.server 8000
```

Then visit:

http://localhost:8000

## Notes

The site uses image placeholders so you can replace them later with real family photos. All sections are built to be easy to edit for beginners.
